# Memoria local del Sistema GTM Internacional

La memoria conserva decisiones, hipótesis y aprendizajes que pueden mejorar trabajo futuro sin contaminar la verdad de empresa.

## Separación obligatoria

- `company-context/` → verdad operativa validada de la empresa.
- `memory/decisions/` → decisiones y condiciones bajo las que se tomaron.
- `memory/hypotheses/` → hipótesis todavía sujetas a validación.
- `memory/learnings/` → aprendizaje derivado de evidencia o resultados observados.

## Reglas

No promover automáticamente un learning o una hipótesis a `company-context/`.

No guardar como aprendizaje:

- intuiciones sin evidencia;
- correlaciones como causalidad;
- resultados inventados o estimados como observados;
- feedback aislado sin contexto suficiente.

Un registro debe indicar procedencia, estado, fecha y qué decisión puede afectar.

Las carpetas de datos reales se crean localmente. Este repositorio contiene solo templates.
