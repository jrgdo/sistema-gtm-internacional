# Cuándo necesitas personalización profesional

El sistema público ofrece una arquitectura y metodología general. Algunas empresas necesitan adaptar el sistema a su sector, modelo comercial y governance.

## Señales habituales

- el ICP depende de aplicaciones o criterios técnicos específicos;
- el score de mercados necesita pesos propios;
- el perfil de distribuidor cambia mucho por país o línea;
- existen reglas complejas de pricing, claims o canal;
- varios equipos deben usar el mismo proceso;
- el workflow real incluye ingeniería, legal, operaciones o customer service;
- se necesitan nuevas skills específicas del sector;
- la empresa quiere integrar datos internos o automatizar handoffs.

## Personalización útil

Puede incluir:

- adaptación de criterios y taxonomías;
- company context engineering;
- scorecards propios;
- workflows por rol;
- nuevas skills especializadas;
- lenguaje/brand governance;
- approvals;
- integraciones y tools;
- tests y evaluaciones propios.

## Diferencia clave

La personalización no consiste en “hacer el prompt más largo”. Consiste en convertir la forma real de trabajar de la empresa en una arquitectura explícita, evaluable y mantenible.
