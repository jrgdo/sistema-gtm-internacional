# Autodiagnóstico de madurez GTM + IA

Este autodiagnóstico ayuda a decidir si el sistema público es suficiente o si el problema real requiere personalización, integración o automatización profesional.

## Preguntas

Marca `Sí`, `Parcial` o `No`.

1. ¿La información de empresa, oferta, ICP y mercados está suficientemente estructurada?
2. ¿El equipo evalúa mercados con criterios consistentes?
3. ¿La investigación comercial termina en una decisión o siguiente validación clara?
4. ¿Los distribuidores se comparan con criterios comunes y evidencia verificable?
5. ¿La investigación de cuentas diferencia hechos, señales e hipótesis?
6. ¿Los aprendizajes de reuniones vuelven a un sistema compartido?
7. ¿Claims, pricing y compromisos sensibles tienen reglas de aprobación claras?
8. ¿El equipo evita repetir manualmente la misma investigación en distintas herramientas?
9. ¿Existe una fuente fiable para pipeline, cuentas, partners y resultados?
10. ¿Las automatizaciones actuales tienen ownership, manejo de errores y revisión humana?

## Niveles orientativos

### Nivel 1 — Uso individual de IA
Información dispersa, prompts individuales, resultados poco estandarizados.

El repositorio público puede aportar gran parte del valor inicial: contexto, skills y workflows.

### Nivel 2 — Workflow asistido
El proceso está definido, pero depende de pasos manuales, copy/paste y criterio individual.

Siguiente necesidad habitual: personalización de criterios, templates, governance y skills.

### Nivel 3 — Workflow conectado
El proceso necesita CRM, Drive, ERP, fuentes externas, reporting o persistencia compartida.

Siguiente necesidad habitual: integraciones, tools, permisos y automatización con human-in-the-loop.

### Nivel 4 — Operating System
Varias funciones, procesos recurrentes, monitoring, routing, approvals, analytics y aprendizaje deben coordinarse de forma fiable.

Requiere arquitectura empresarial: estado, observabilidad, seguridad, evaluación, mantenimiento y governance.

## Principio

La madurez no se mide por cuántos agentes usa una empresa, sino por la calidad con la que conecta **contexto → decisión → ejecución → evidencia → aprendizaje**.
