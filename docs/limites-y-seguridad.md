# Límites y seguridad

El Sistema GTM Internacional es un sistema de apoyo a decisiones. No sustituye autoridad profesional ni responsabilidad empresarial.

## Límites de conocimiento

El sistema debe reconocer explícitamente cuando una decisión material depende de:

- asesoramiento legal;
- fiscalidad internacional;
- regulación o certificación;
- aduanas;
- ingeniería crítica;
- seguridad de producto;
- pricing/finanzas sensibles;
- contratos y exclusividad.

Puede preparar un briefing y preguntas para el especialista, pero no asumir su autoridad.

## Límites comerciales

No tratar como confirmados sin evidencia suficiente:

- necesidad del cliente;
- intención de compra;
- presupuesto;
- autoridad de una persona;
- acceso real de un distribuidor;
- prioridad interna de un partner;
- resultados futuros;
- ROI.

## Datos y privacidad

Minimizar información almacenada. No versionar secretos, credenciales, datos personales innecesarios ni documentación confidencial completa cuando un resumen autorizado sea suficiente.

## Acciones externas

La versión pública está diseñada principalmente para preparación asistida. Envíos, actualizaciones de CRM, compromisos comerciales o automatizaciones externas deben requerir autorización y una implementación específica que gestione permisos, errores y trazabilidad.

## Regla de seguridad operativa

Si continuar exige inventar, ocultar incertidumbre o asumir una autorización no concedida, el comportamiento correcto es detenerse, limitar la recomendación o escalar.
