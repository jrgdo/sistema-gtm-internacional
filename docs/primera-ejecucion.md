# Primera ejecución

## Objetivo

Conseguir que el sistema entienda suficiente contexto de la empresa antes de hacer trabajo GTM sustantivo.

## Secuencia recomendada

1. Instala las skills o clona el repositorio.
2. Pide: `Configura el Sistema GTM Internacional para mi empresa.`
3. El sistema comprueba si existe `company-context/STATUS.md`.
4. Si no existe, inicializa el workspace.
5. Revisa documentos disponibles antes de preguntar.
6. Ejecuta `onboarding-empresa` por bloques cortos.
7. Presenta hechos confirmados, inferencias, conflictos y gaps.
8. Solicita validación humana de elementos materiales.
9. Actualiza `STATUS.md`.
10. Declara qué trabajo GTM ya está habilitado.

## Documentos útiles

No son obligatorios, pero pueden reducir preguntas:

- catálogo;
- fichas técnicas;
- presentación comercial;
- plan export;
- documentación de clientes/segmentos;
- brand guide;
- políticas de canal;
- claims aprobados;
- restricciones de capacidad/logística;
- materiales comerciales vigentes.

## Resultado esperado

El sistema no debe terminar simplemente con “onboarding completado”. Debe indicar para qué decisiones el contexto es suficiente y qué sigue siendo parcial, conflictivo o desconocido.
