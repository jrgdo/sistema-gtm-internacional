# Ejemplo de priorización de mercados

Este ejemplo ilustra el tipo de razonamiento esperado; no contiene datos reales.

## Decisión

¿En cuál de Francia, Italia o Polonia debería IberFluid Systems concentrar primero una validación comercial de seis meses?

## Criterios

Separar:

- atractivo del mercado;
- capacidad de ganar con el modelo actual;
- fricción y riesgo.

## Resultado ilustrativo

No asignar un ganador por intuición. Si Francia muestra mayor evidencia de demanda pero también alta competencia, e Italia ofrece mejor acceso vía partners conocidos, el sistema debe hacer visible ese trade-off.

Si Polonia presenta datos insuficientes sobre canal técnico, el resultado correcto puede ser `REQUIERE_EVIDENCIA`, no un score bajo inventado.

## Siguiente acción

Investigar únicamente los gaps que puedan cambiar el ranking y diseñar una validación de campo para el mercado mejor soportado.
