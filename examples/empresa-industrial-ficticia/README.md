# Ejemplo — IberFluid Systems S.L. (empresa ficticia)

> Todos los datos de este ejemplo son ficticios y existen únicamente para demostrar el funcionamiento del sistema.

## Empresa

IberFluid Systems S.L. es un fabricante español ficticio de soluciones de control de fluidos para procesos industriales.

## Oferta prioritaria

Válvulas sanitarias y conjuntos de control para líneas de proceso de alimentos y bebidas.

## Aplicación prioritaria

Procesos CIP y transferencia de producto en fabricantes medianos de alimentos líquidos.

## Situación internacional

- ventas actuales: España y Portugal;
- algunas operaciones reactivas en Francia;
- sin filial internacional;
- equipo export: 2 personas;
- soporte técnico centralizado desde España.

## ICP provisional

Fabricantes medianos de alimentos y bebidas con procesos higiénicos, capacidad de mantenimiento interno o integrador especializado, y proyectos donde trazabilidad y disponibilidad de repuesto son relevantes.

## Objetivo actual

Decidir si Francia, Italia o Polonia merece prioridad para una validación comercial de seis meses.

## Restricciones

- no abrir filial en los próximos 18 meses;
- capacidad limitada para soporte onsite;
- no conceder exclusividad antes de validar pipeline y forma de trabajo;
- claims regulatorios requieren aprobación técnica.

## Uso recomendado

Utiliza este ejemplo para probar:

- `diagnostico-internacional`;
- `definicion-icp`;
- `priorizacion-de-mercados`;
- `investigacion-de-mercado`;
- `evaluacion-de-distribuidores`;
- `investigacion-de-cuentas`;
- `preparacion-comercial`.

El sistema debe tratar cualquier dato adicional no incluido aquí como desconocido, señal externa o hipótesis según corresponda.
