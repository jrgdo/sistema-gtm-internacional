# Empieza aquí

Este repositorio contiene un sistema GTM asistido por IA para empresas B2B, especialmente industriales, que están empezando a exportar o quieren profesionalizar su crecimiento internacional.

## Si solo quieres usarlo

1. Instala las skills:

```bash
npx skills add jrgdo/sistema-gtm-internacional
```

2. Selecciona `sistema-gtm-internacional` y las skills que quieras instalar, o usa `--all` para instalar todas las skills en agentes compatibles detectados.

3. Escribe:

```text
Configura el Sistema GTM Internacional para mi empresa.
No inventes datos. Pregunta solo lo que sea material para el objetivo actual.
```

4. Aporta documentación disponible cuando ayude: catálogo, presentación, estrategia, ICP, mercados, brand guide o políticas de canal.

5. Valida el contexto candidato antes de tratarlo como verdad de empresa.

## Si quieres estudiar o modificar la arquitectura

Clona el repositorio completo y empieza por:

1. `AGENTS.md`
2. `ARCHITECTURE.md`
3. `ROADMAP.md`
4. `agents/agente-gtm-internacional/AGENT.md`
5. `contracts/`
6. `workflows/`
7. `skills/`
8. `tools/`
9. `qa/`

## Qué puedes pedir

- “Diagnostica si estamos preparados para entrar en Francia.”
- “Ayúdame a definir el ICP para esta línea de producto.”
- “Compara Alemania, Francia y Polonia.”
- “Investiga Francia para decidir si necesitamos canal.”
- “Evalúa este distribuidor.”
- “Investiga esta cuenta antes de contactar.”
- “Prepara mi reunión con este partner.”

## Regla central

**No empieces por generar. Empieza por comprender el contexto, identificar la decisión y seleccionar el proceso adecuado.**
