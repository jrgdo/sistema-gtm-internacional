# Workflow — Diagnosticar expansión

## Objetivo
Determinar si la empresa está suficientemente preparada para ejecutar una ambición internacional concreta y qué gaps deben resolverse primero.

## Precondiciones
- contexto mínimo de empresa;
- oferta/aplicación prioritaria;
- objetivo internacional definido.

## Secuencia
1. Validar contexto relevante.
2. Ejecutar `diagnostico-internacional`.
3. Si el ICP es un gap material, ejecutar `definicion-icp` y volver al diagnóstico solo si nueva información cambia readiness.
4. Clasificar gaps por impacto y controlabilidad.
5. Preparar condiciones para avanzar y siguiente decisión.

## Gates
- contexto insuficiente → onboarding;
- conflicto material → validación humana;
- cuestión legal/técnica crítica → escalado profesional.

## Output
Readiness contextual, gaps críticos, condiciones de avance, confianza y siguiente acción.
