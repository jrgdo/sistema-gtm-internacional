# Preguntas de validación para distribuidores

## Acceso al mercado

- ¿Qué tipos de clientes activos tenéis en este segmento?
- ¿Qué aplicaciones cubrís actualmente?
- ¿Qué cuentas objetivo podríais abordar con nuestra oferta?
- ¿Podéis compartir ejemplos concretos de oportunidades comparables?

## Cobertura

- ¿Qué regiones cubre realmente vuestro equipo?
- ¿Quién visita estas cuentas y con qué frecuencia?
- ¿Qué cobertura depende de terceros o subdistribuidores?

## Capacidad técnica

- ¿Quién asumiría preventa y soporte técnico?
- ¿Qué experiencia tiene el equipo con esta aplicación?
- ¿Cómo gestionáis pruebas, demos, muestras o incidencias?

## Portfolio

- ¿Qué marcas o soluciones podrían competir con la nuestra?
- ¿Qué productos complementarios podrían facilitar la entrada?
- ¿Cómo priorizáis nuevas marcas dentro del portfolio?

## Operativa comercial

- ¿Cómo gestionáis pipeline y forecast?
- ¿Qué reporting podéis compartir?
- ¿Cómo definís una oportunidad cualificada?
- ¿Qué información esperáis recibir del fabricante?

## Compromiso

- ¿Qué acción concreta podéis realizar durante las próximas semanas para validar encaje?
- ¿Qué cuentas o aplicaciones propondríais como primer test?
- ¿Quién sería responsable internamente?

## Reglas

No convertir una respuesta verbal en evidencia demostrada cuando requiera verificación.

No hacer todas las preguntas por defecto. Seleccionar las que resuelven los unknowns materiales del candidato.
